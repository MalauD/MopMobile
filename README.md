## About the Project

This is the mobile client of the app [MopRs](https://github.com/MalauD/MopRs). Most of the features from the web app is included.

## How to build ?

This project now uses Expo tooling with Continuous Native Generation (CNG).
Because the app depends on native modules such as `react-native-track-player`, `react-native-fast-image`, and `@react-native-cookies/cookies`, you need an Expo development build rather than Expo Go.

Install dependencies first:

```bash
npm install
```

Then start the Expo dev server and run a development build:

```bash
npm run start
npm run android
```

On iOS, use:

```bash
npm run ios
```

Useful additional commands:

```bash
npm run doctor
npm run prebuild
```

The `android/` and `ios/` folders are generated by Expo prebuild and are intentionally ignored in git.
If you need to refresh them locally, run:

```bash
npm run prebuild
```
